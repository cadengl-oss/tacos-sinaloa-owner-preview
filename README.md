# Tacos Sinaloa y Carnicería — Muchacha/Taco Mark Concept

Art direction: SiteInspire Muchacha-inspired motif system, translated into a distinct Taco Mark identity.

## Principles
- Taco silhouette is the recurring graphic device: photo mask, hover icon, motion cue, footer mark.
- Blush + deep green is the primary identity palette; red is a supporting accent.
- Real business imagery is stored locally under /assets.
- Content remains visible if JS fails; motion is progressive enhancement only.
- EN/ES toggle, call and directions flows remain functional.
- Business/menu details should still be owner-verified before a production launch.
